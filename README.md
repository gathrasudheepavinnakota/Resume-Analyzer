# Resume-Analyzer
An AI-powered Resume Analyzer designed to optimize applications for modern ATS. Built with Python and NLP, this tool automatically parses resumes to extract skills, experience, and contact data. It features a semantic matching engine that evaluates compatibility against job descriptions, scoring fit and identifying missing keywords.
    The core of the system relies on advanced Information Extraction and Named Entity Recognition (NER) to pull names, contact details, universities, degrees, and corporate tenures out of raw text streams. Moving beyond brittle, literal keyword matching, the tool leverages dense text embeddings and cosine similarity to map conceptual alignment between a candidate's background and a job post, effectively matching related terms like "distributed systems" with "microservice architecture." To ensure accurate evaluations, the application employs a weighted multi-dimensional scoring matrix that independently calculates sub-scores for technical skills alignment, total years of experience fit, academic degree mapping, and lexical TF-IDF token overlap.
    The application serves both job seekers and recruiters through an interactive dashboard built on modern UI frameworks like Streamlit or React, providing real-time data visualization, keyword gap analysis, and visual gauges of candidate performance. It integrates generative AI models via modern LLM APIs to provide context-aware text rewrites and actionable optimization tips. The codebase runs on Python 3.10+ and relies on robust open-source libraries including spaCy for text tokenization and lemmatization, scikit-learn for mathematical similarity, and PyMuPDF or python-docx for reliable document parsing.
    Planned future updates aim to scale the tool into an enterprise-grade recruitment platform. Upcoming features include native OCR engines to scan image-based or poorly formatted PDF documents, bulk candidate ranking to let HR departments batch-upload and sort hundreds of resumes simultaneously, and automated interview preparation tools that dynamically generate behavioral questions tailored to a candidate's identified skill gaps.
